# Mirror Reference v5

PureRef風の軽量リファレンスボード。ビルド不要の静的Webアプリです。

## 主な機能
- 画像のドラッグ＆ドロップ、ファイル追加、クリップボード貼り付け
- 画像追加時は現在の表示領域の中心付近に自動配置。既存画像と重なりにくい位置を探して、渦巻き状に分散します
- 画像をドラッグして移動
- 空白部分のドラッグで複数画像を範囲選択
- 四隅のハンドルで拡大縮小、上部の丸ハンドルで回転
- `Space` + ドラッグでキャンバス移動
- `Delete` / `Backspace` で選択画像を削除
- マウスホイール・トラックパッド・＋／−ボタンで滑らかにズーム
- 選択画像／全画像／ワークスペース全体の左右反転
- 操作パネルの左右切り替え
- スポイトとHSBカラー分析、色ごとの比率表示
- JSONプロジェクト保存・読み込み、PNG書き出し

## GitHub Pages
`index.html` と `README.md` をリポジトリ直下に置き、Settings → Pages → Deploy from a branch → `main` / `/(root)` を選択してください。
