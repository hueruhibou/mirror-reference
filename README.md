# Mirror Reference v8

PureRef風の軽量リファレンスボード。ビルド不要の静的Webアプリです。

## 操作
- 画像をクリック：選択して最前面に移動
- 同じ画像をすばやく2回クリック：その画像を左右反転
- 画像をドラッグ：移動
- 空白部分をドラッグ：複数画像を範囲選択
- `Shift` + レイヤークリック：選択を追加／解除
- 四隅のハンドル：拡大縮小
- 上側の丸ハンドル：回転
- `Space` + ドラッグ：キャンバス移動
- `←` `↑` `→` `↓`：選択画像を10pxずつ移動
- `Shift` + 十字キー：選択画像を50pxずつ移動
- `Delete` / `Backspace`：選択画像を削除
- マウスホイール／トラックパッドのピンチ：ポインター位置を中心にズーム。累積約100px相当の操作で約1.5倍（または逆数）を目安に調整
- 上部の `＋` / `−`：画面中央を基準に大きめのステップでズーム
- `全体表示`：ワークスペース全体へフィット
- 反転メニュー：選択画像／全画像／ワークスペース全体を左右反転
- 画像一覧はサムネイル・ファイル名・サイズを表示
- 操作パネルの左右切り替え
- スポイトとHSBカラー分析、色ごとの比率表示
- JSONプロジェクト保存・読み込み、PNG書き出し

## GitHub Pages
`index.html` と `README.md` をリポジトリ直下に置き、Settings → Pages → Deploy from a branch → `main` / `/(root)` を選択してください。
