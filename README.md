# Mirror Reference

PureRef風の軽量リファレンスボード。画像を自由に配置し、左右反転や色の比率確認をしながら比較できます。ビルド不要の静的Webアプリです。

## 主な機能

- 画像のドラッグ＆ドロップ、ファイル追加、クリップボードからの貼り付け
- 画像を直接ドラッグして移動
- `Space` を押しながらドラッグしてキャンバスをパン（ハンドツール）
- 選択画像ごとの倍率・回転・透明度調整
- 反転対象を選択可能
  - 選択画像：選択中の画像だけを左右反転
  - 画像をすべて：すべての画像内容を左右反転。配置は維持
  - ワークスペース全体：画像内容と配置をまとめて左右反転
- 操作パネルを左側・右側に切り替え（設定はブラウザーに保存）
- スポイトで色を取得し、HSB（色相・彩度・明度）で表示
- 選択画像の主要色と使用比率をバーで表示
- 編集可能なプロジェクトデータ（JSON）の保存・読み込み
- ボード全体をPNGとして書き出し

## 使い方

1. `index.html` をブラウザーで開きます。
2. 画像をキャンバスへドラッグ＆ドロップするか、「画像追加」から選びます。
3. 画像を直接ドラッグして移動します。
4. `Space` を押しながらドラッグすると、キャンバス全体を移動できます。
5. 上部の「反転対象」で対象を選び、「左右反転」を押します。
6. 上部の「パネル」で操作パネルを左右に切り替えます。
7. 「保存」で編集用JSON、「PNG」で画像を書き出します。

## キーボード操作

| キー | 操作 |
|---|---|
| `Space` を押しながらドラッグ | ハンドツール（キャンバス移動） |
| `Delete` | 選択画像を削除 |
| `⌘S` / `Ctrl+S` | プロジェクトを保存 |

## GitHub Pages で公開する

1. GitHubで新しいリポジトリを作成します。
2. このフォルダー内の `index.html` と `README.md` をリポジトリ直下へアップロードします。
3. **Settings → Pages** を開きます。
4. **Deploy from a branch** を選び、`main` ブランチ / `/(root)` を指定して保存します。
5. 数分後、表示されたGitHub PagesのURLから利用できます。

## データとプライバシー

画像処理とプロジェクトデータの生成は、基本的にブラウザー内で行います。プロジェクト保存では画像データを含むJSONファイルがダウンロードされます。必要なデータはブラウザーを閉じる前に保存してください。

## 注意

- 現在は単一HTMLファイルの試作版です。
- 画像の色分析は縮小サンプルに基づく概算です。比率は透明ピクセルを除くサンプル全体を分母として計算します。
- ブラウザーやOSによって、クリップボードなど一部機能の動作が異なる場合があります。
