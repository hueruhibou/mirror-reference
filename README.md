# Mirror Reference

PureRef風の、画像を自由に配置して比較するための軽量リファレンスボードです。インストール不要で、ブラウザー上で動作します。

## 主な機能

- 画像のドラッグ＆ドロップ、ファイル追加、クリップボードからの貼り付け
- 画像ごとの移動、拡大縮小、回転、透明度調整
- 選択画像の水平反転（ボタンまたは `Space`）
- `H` キーを押しながらドラッグしてキャンバスを移動
- スポイトで色を取得し、HSB（色相・彩度・明度）で表示
- 選択画像の主要色と画像全体に対するおおよその占有率を表示
- 編集可能なプロジェクトデータ（JSON）の保存・読み込み
- ボード全体をPNGとして書き出し

## 使い方

1. `index.html` をブラウザーで開きます。
2. 画像をキャンバスへドラッグ＆ドロップするか、「画像追加」から選びます。
3. 画像をクリックして選択し、右側のパネルで透明度・回転・倍率を調整します。
4. `Space` または「水平反転」で、選択中の画像を左右反転します。
5. 「保存」で編集用JSON、「PNG」で画像を書き出します。

### キーボード操作

| キー | 操作 |
|---|---|
| `V` を押しながらドラッグ | 選択画像を移動 |
| `H` を押しながらドラッグ | キャンバスを移動 |
| `Space` | 選択画像を水平反転 |
| `Delete` | 選択画像を削除 |
| `⌘S` / `Ctrl+S` | プロジェクトを保存 |

## GitHub Pages で公開する

このプロジェクトはビルド工程のない静的Webアプリです。

1. GitHubで新しいリポジトリを作成します。
2. このフォルダー内の `index.html` と `README.md` をリポジトリ直下へアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Deploy from a branch** を選び、公開元を `main` ブランチ / `/(root)` に設定して保存します。
5. 数分後、表示されたGitHub PagesのURLから利用できます。

## データとプライバシー

画像処理とプロジェクトデータの生成は、基本的にブラウザー内で行います。プロジェクトを保存すると、画像データを含むJSONファイルがダウンロードされます。ブラウザーのタブを閉じる前に必要なデータを保存してください。

## 注意

- 現在は単一HTMLファイルの試作版です。
- ブラウザーやOSによって、クリップボードへのアクセスなど一部機能の動作が異なる場合があります。
- 画像の色分析は縮小サンプルに基づく概算です。表示割合は透明ピクセルを除くサンプル全体を分母として計算します。
